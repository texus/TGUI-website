Detailed Description

Texture implementation that uses Vulkan.

The image has the VK_FORMAT_R8G8B8A8_UNORM format and is kept in the VK_IMAGE_LAYOUT_SHADER_READ_ONLY_OPTIMAL layout.

Loading the texture submits the upload to the queue without waiting for it to finish. Work that accesses the image must be submitted to the same queue, with a dependency on VK_PIPELINE_STAGE_FRAGMENT_SHADER_BIT as source stage.
