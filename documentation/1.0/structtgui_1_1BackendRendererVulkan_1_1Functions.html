Detailed Description

Vulkan functions that are used by TGUI.

The surface and swapchain functions are nullptr when the VK_KHR_surface instance extension or VK_KHR_swapchain device extension weren't enabled. The debug utils functions are nullptr when the VK_EXT_debug_utils instance extension wasn't enabled.
