Detailed Description

Backend renderer that uses Vulkan.

The renderer doesn't create any Vulkan instance or device itself, these have to be provided by the user. TGUI doesn't link to the Vulkan loader, all Vulkan functions are loaded via the provided vkGetInstanceProcAddr. All TGUI functions must be called from the same thread, as TGUI submits work to the provided queue when textures are loaded. These uploads are submitted without waiting for them to finish, so any work that accesses the images of TGUI textures has to be submitted to the same queue.
