Detailed Description

Vulkan objects that TGUI needs to render.

The queue must support graphics operations. It also has to support presenting to the window surface if the gui.mainLoop() function is used. Command buffers in which the gui is drawn must be submitted to this queue, as texture uploads are submitted to it as well. The objects must remain alive for as long as TGUI uses them.
